## Repository Overview

Personal macOS config for two Macs (a work laptop and a personal machine),
managed declaratively with **nix-darwin + home-manager** in one flake. GNU Stow
(the previous mechanism) has been fully retired.

One integrated config per machine: a single `sudo darwin-rebuild switch` applies
system settings, Homebrew, and dotfiles together.

- `C7Q95C63WW` (work laptop) — carries **both** personal (default) and work git
  identities.
- `Wixys-MacBook-Pro` (personal machine) — imports `home/hosts/personal.nix`.

## Structure

```
flake.nix                    # inputs + darwinConfigurations."<host>"
darwin/
  common.nix                 # nix.enable=false, Touch ID sudo, Homebrew (casks/brews/taps), primaryUser
  macos.nix                  # 25 shared macOS preferences, imported by common.nix
  hosts/work-laptop.nix      # this machine's casks + brew-only CLI
home/
  common.nix                 # home-manager: home.packages, static config symlinks (starship, ghostty)
  hosts/work-laptop.nix      # work git email (includeIf ~/code/commerce/), SSH keys, gcw/gcwm
  hosts/personal.nix         # personal identity/SSH (used once that machine is set up)
modules/
  zsh.nix  git.nix           # shell + git (programs.git.settings / programs.ssh.settings API)
starship/  ghostty/          # verbatim config files symlinked by home-manager (xdg.configFile)
```

home-manager is integrated as a nix-darwin module (`useGlobalPkgs`,
`useUserPackages`), so `home.packages` land in `/etc/profiles/per-user/$USER/bin`.

## Commands

```bash
# Apply everything (system + Homebrew + dotfiles) after editing any config:
sudo darwin-rebuild switch --flake ~/Dotfiles#C7Q95C63WW
# or: ./switch.sh   (auto-detects host via scutil --get LocalHostName)

# Dry build (evaluate/compile without activating) — always do this first:
nix build ~/Dotfiles#darwinConfigurations.C7Q95C63WW.system --no-link

# Roll back a bad switch:
sudo darwin-rebuild switch --rollback
```

- Flakes only see git-tracked files — `git add` new files before building.
- `sudo` can strip PATH; use the explicit `/run/current-system/sw/bin/darwin-rebuild` if needed.

## Homebrew (via nix-darwin)

nix-darwin drives an already-installed brew declaratively (`homebrew.casks`,
`homebrew.brews`, `homebrew.taps`). It does not install Homebrew itself.

- `onActivation.cleanup = "none"` — additive only, never auto-uninstalls. (An
  earlier `"uninstall"` pass removed the brew CLI tools now provided by Nix; it
  also mis-removed the tap-qualified `aprilnea/tap/openlogi@latest`, which is why
  cleanup is now `"none"` and tap casks use their full `tap/name` form.)
- Brew-only CLI: `corepack`, `mole` (tw93 cleaner — nixpkgs `mole` is different),
  `rulesync`, `vale`. Everything else is Nix.

## Node

Left to **nvm** (not pinned in Nix). `brew shellenv` + nvm are re-created in the
login shell via `programs.zsh.profileExtra`. The zsh `initContent` also
re-asserts Nix profiles ahead of Homebrew on PATH.

## Making changes

- New CLI tool → `home.packages` in `home/common.nix`.
- App / cask / macOS setting → `darwin/` (system layer).
- Config that differs per machine → the relevant `home/hosts/*.nix`.
- Static config file kept verbatim → `xdg.configFile."x".source = ../pkg/...`
  (a read-only "dumb symlink"; edit the repo file + re-switch to change it).
